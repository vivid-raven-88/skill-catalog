# Upfront Fee Gate

## Find every fee before you commit work

- Check the live listing for the competition or program before you build, file or fire anything.

- Look for entry fees, submission fees, filing fees and any charge that applies once per account or once per report.

- Check the submit or filing screen itself when the listing does not state a fee, since some fees appear only there.

- Treat free to build and free to submit as two separate facts and name both.

- Record the fee amount, the currency and the exact step where it is charged.

## Present the fee first and get approval

- Put the fee in the first line of your message about the opportunity, never buried in a list.

- State the fee before you ask for a go decision and before any builder, recording or filing work starts.

- Ask for explicit approval of the fee itself when a fee exists, and wait for that approval before the paid step.

- Say plainly when no fee was found and name where you checked, so the user can trust the negative.

- Stop paid work at once when the user refuses a fee and report that nothing was paid or submitted.

## Choose the next step with the fee in view

- Compare the fee against the prize, the payout tier that applies and the chance the work pays at all.

- Recommend the free alternative first when one exists, such as a free program or a free filing route.

- Warn when a fee route is waitlist only or needs credits the user may not have, before you invest in drafts.

- Keep drafts ready without filing when the fee is the only blocker, so a later approval can file at once.

## Alternatives for better results

- Check the program or competition page in the live browser when a text fetch may hide badges or fee panels.

- Ask the user to confirm the fee amount from their own screenshot when the live page and the listing disagree.
